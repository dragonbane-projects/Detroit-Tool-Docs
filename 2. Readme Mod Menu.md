
# **Detroit Ingame Mod Menu**

## The Production Menu
 - The game now starts on the production "PROD" chapter select screen. This is the internal chapter selector Quantic uses during development. It has a few advantages such as faster response times as the actual main menu and the fact you can jump to any sub scene of Crossroads and Battle for Detroit instantly. If you prefer the game to boot with the regular Chloe menu, create an empty text file called "__skipProdMenu.txt" in the "DetroitBecomeHuman\Mods\DB0" folder. No  contents inside needed. Likewise you can create a "__keepBootMovies.txt" file in the same folder if you prefer to keep the boot logo videos for a 100% authentic experience
 - A big difference with the PROD menu is that all of the chapters will load with default choices. This means no one has died for example or that all relationship gauges are at 0%. Usually you can access anything you want anyway with the [Cheats](#cheats) menu, but if you prefer having your saves or the old menu for whatever reason, you can select the MENU entry on the bottom-right of this screen to load the regular Chloe main menu
 - This menu can be operated with a controller (d-pad) or with the movement keys on PC (arrow buttons). Confirmation is with X (controller) or Enter (PC). NOTE: If you find that the down arrow on PC acts as a confirm button too, change the "move down" alternative key binding in the game's PC options to some button you never use freeing the down arrow, but keeping the S key in primary or whatever you use there
## Existing Save Files
>[!WARNING]
It is strongly advised against to load up any continue save or chapter checkpoint when first installing the Mod menu or when switching between Mods. These overwrite any Mods and usually instantly break the mod tools. The cheats are usually just as fast, so you will mostly no longer need these. If you need to load a save, only load those that start a chapter from the beginning.

## Mod Menu

### Controls
- After you are ingame, you can open my mod menu at any time by using the R3 button (controller) or F12 (PC)
- Operation is the same as the production menu
- To navigate back one layer if you are multiple menu layers in, you can use Circle (pad) or the Escape key (PC). Using R3/F12 at any point will fully close the menu again
<a name="controls-page-menu"></a>
- If you happen to be in a long list menu, you can cycle pages of items using L1/R1 (pad) or F1/F2 (PC)
<a name="controls-slider-menu"></a>
- Pages where you can adjust a number value, d-pad up/down (pad) or W/S (PC) will adjust the value up/down. This button can be held and will eventually speed up the increase/decrease. On PC you can also use the mousewheel. Additionally a multiplicator for faster adjustments can be set with d-pad right/left (pad) or A/D (PC)
<a name="controls-free-type-menu"></a>
- There are also some pages that expect an arbitrary name or number input. This works by typing it in via the keyboard. Enter to confirm and backspace to delete one character
<a name="controls-alt-confirm"></a>
- NOTE: Select (pad) and left mouse click (PC) also work as a confirmation key alongside X/Enter on my menus. When you pause the game using the menu, the game turns off the X/Enter button, in this case you absolutely need the Select/left mouse click button to keep operating the menu and also unpause the game again

### Menu Item Explanation:

#### **Saves**
Basically like having infinite resume saves at whatever point you want. For example you can save on the Hostage terrace directly in the final Daniel confrontation and loading this save will start you in that cutscene even though the game doesn't give you a save point there normally. It's basically free save. There are 2 categories of saves. Global and Chapter. Global means the save is available from anywhere you open the Save menu. 
Chapter means those saves only show up if you are already in Hostage for example (and it shows a different set of saves if you are in a different chapter). This is useful for organization.

As previously mentioned, I generally don't recommend using saves, but this makes it easier.

When you are prompted for a save name - this is a free typing menu. See [Controls](#controls-free-type-menu) for operation notice.

The list index of your saves is kept in the following file: DetroitBecomeHuman\Mods\DB0\_savefileList.lua
This file can be edited with Notepad. If you wish to remove a custom save or rename one, you need the following approach:
 1. Locate Detroit's actual save directory. Rename or delete the file from there. Custom saves are found under: Saved Games\Quantic Dream\Detroit Become Human\INTER_1\Checkpoints-cv1-sv7\DB0
 2. Edit the _savefileList.lua file. Find your save in there and rename the entry or remove it entirely (including the quotes and possible comma)


#### **Game Speed**
 - You can use this to pause the game (0x) but also make it play up to 8x as fast to go through scenes quicker. If the game is paused with 0x, **the menu controls change!** See [Controls](#controls-alt-confirm)
 - When paused, you can also frame advance (see hotkey section)
 - Audio can be paused individually
 - *Auto Pause on New Scene* can be used to automatically pause the game on frame 0 of a new chapter, so you can setup the scene before anything happens if required


#### **Cheats**
Basically allows you to manipulate selective game variables on a case by case basis and also usually skip to any chapter part instantly.
This menu contains the Quantic Dream created development cheats. You can ignore all but "Master" and chapter specific options. Meaning you can ignore "Generic", "Flowchart" and "Savegame" entirely. These are never relevant. 
Master and other "folders" that can appear depending on chapter are the useful ones.

When you use a cheat commonly called "Enable cheats" under Master this will add new options right away. To see them go back one level and then back in. Then you get to see the new cheats you just enabled. 
Quantic Dream is fairly random what cheats they add, but usually it's useful cheats. Some are however broken or they need to be used in a specific order. After all these are development remnants. Practice makes you better at using them.

When you use a cheat that starts with "GM" and contains "= true/false" in its name this is a cheat that does nothing but set this particular game variable. Quantic typically adds these to chapters where you need them to trigger specific scenes.


#### **Player**
The Player menu has some useful tools for the player:
 - Collisions: Ability to disable collisions which allows you to walk through walls and in the air
 - Fast Walk: Walk twice as fast
 - Warp Up: Teleport into the air. Only works if you disable collisions beforehand
 - Enable Gameplay: Force enable gameplay. This allows to walk in cutscenes for example and is useful if you softlock yourself. Mostly only relevant for development related situations
 - Position Display: As the name implies, this displays the current world coordinates of the player


#### **FreeCam**
The FreeCam. Using this menu option immediately enables the camera. For controls see the [FreeCam Controls](#the-freecam-controls) section at the bottom. The following options exist:

 - Properties: Allows to manipulate the DoF and F-Stop value on a very precise basis. See [Controls](#controls-slider-menu). DoF can also be set roughly using 2 hotkeys, see [FreeCam Controls](#the-freecam-controls)
 - Reset FreeCam: Reset the FreeCam to the player or current cutscene position
 - Warp Camera to Player/Warp Player to Camera: Exactly as the name says
 - CloseUp Lighting: Disable/Enable the cutscene close-up lighting while in FreeCam. Can sometimes be desirable to have off for video recordings as the constant lighting switches can ruin immersion
 - Info Display: Displays camera position information
 - Disable FreeCam: Turn the FreeCam off (F1 hotkey also works)


#### **Characters**
Allows to manipulate Characters and Objects in the chapter.
Visible Only will show both Characters and Objects in a single list, as long as they are currently *completely* in your camera view.
The character/object list can stretch across multiple pages. See [Controls](#controls-page-menu) section to find out how to switch pages. The active player character for this chapter is quickly available under the special name: "0GMCurrentPlayer"
 - Show/Hide: Show/Hides the character/area
 <a name="characters-set-catalog"></a>
 - Set Catalog: Change the character model in real time by typing in its ID. This is a free typing menu. See [Controls](#controls-free-type-menu) section for operation notice. A list of available catalog IDs is available under: [Catalog List](Resources/CatalogList.json)
 - Enable Cloth Physics/Disable Cloth Physics: Disable Havoc cloth physics on this character. This makes the character leave its hair and clothing behind
 - Teleport To: Warp the player to this character's position
  <a name="characters-apply-composite"></a>
 - Apply Composite: Apply a character composite (a blend between two or more character meshes) to the currently selected character. These are undone when you switch between chapters. Composites are available on request. If you don't have any this option will be missing
 - Unregister (dangerous): Completely remove the character/area from the scene. Can often crash when used with characters (preferably use "Hide" instead whenever possible)




#### **Misc**
 - Pause Sequences: Specifically just pauses any running cutscene keeping the game itself unpaused which is useful in some cases (for example you can still walk and the weather simulation still runs)
 - Kill Sequences: Completely kills all running cutscenes. Can easily softlock so generally avoid. Prefer skipping a single cutscene with the L3/DEL key instead or use a cheat or 8x Game Speed 
 - Skip Chapter: Instantly finishes the chapter as if you finished it normally skipping ahead to the Flowchart screen (no choices are triggered)
- Clear Text/Wireframe: Mostly for me
- Dump Cutscene Stats: Prints currently running cutscene info to the screen if available


#### **Return to PROD Menu**
Returns to the production chapter select screen instantly. Can be used at any point.

**NOTE:**  
While the first chapter you load this way after boot will use default choices, the next one will keep the choices from the first chapter. For example if you first load The Bridge, Hank will be at 0% relationship. If you end the chapter with a -20% relationship and start the chapter immediately again, the relationship is now at -20%. This also works backwards, if you loaded Partners instead the relationship would also start with -20% even if this is normally impossible. This can be very useful to quickly trigger a needed choice in one chapter, then go back into the target chapter to see the effect of this choice play out instantly. Reboot the game to go back to a clean slate if needed.


### Useful Hotkeys
You can ask me to change these for you if you want custom keybindings or don't require certain hotkeys at all:
- L3 (pad) ; Delete (PC) = Skip the currently running cutscene (can be somewhat dangerous to use)
- F1 = Toggle FreeCam (quickly disable or re-enable, useful for First Person Mod if you are stuck)
- F5 = Quicksave (creating a save at your current location in a custom slot)
- F8 = Quickload (loading the quicksave back)
- F10 = Pause/unpause the game (pauses absolutely everything)
- F11 = Pause/unpause all cutscenes (keeps environment effects running)
- P (PC) = Frame advances the game by a single frame (only if the game was previously paused)

You can ask for the following additional hotkeys (tell me the keyboard button):
- Max game speed hotkey
- Slow Motion hotkey
- Pause/unpause button that also pauses audio, not just the visuals

### The FreeCam controls:
These controls can not be changed at this time! Furthermore a NumPad is required to make the most out of the FreeCam.

#### **Main Keyboard**
- Page Up: Move forward
- Page Down: Move backward
- Home (left to Page Up): Lock/Unlock FreeCam (can't move it anymore)
- Arrow Up/Down/Left/Right: Pan FreeCam up/down/left/right (combine with Page Up/Down to move and turn)
- O: Increase DoF
- L: Decrease DoF

#### **NumPad**
-  +(plus) and -(minus) = Increase/decrease the speed of everything (moving/panning/FoV adjustments). Imagine this starting at 5 (neutral) and you can go to 0 (crawl speed) or 20 (fast speed), each press increments/reduces speed by 1. Can tap this button fast
- Num 8/Num 2/Num 4/Num 6: Move FreeCam up/down/left/right (usually keyboards print arrows on these buttons)
- Num 7: Bank/Rotate FreeCam left
- Num 9: Bank/Rotate FreeCam righta
- Num 5: Reset FreeCam (only resets bank angle, pan angle and FoV back to neutral)
- Num 1: Reduce FoV (zoom in). These controls are limitless and doing it too much will create a messed up camera you can easily reset with Num 5 or by doing the opposite FoV control
- Num 3 Increase FoV (zoom out)
- Num 0: Enable/Disable DoF (Depth of Field). Useful if you use FreeCam during a cutscene and the DoF is too strong to see anything clearly outside of the cutscene camera position
- / (devision) and * (multiply) = Some weird alternate FoV control in jumps (avoid these as they often break the camera and everything gets black)

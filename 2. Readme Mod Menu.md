
# **Detroit Ingame Mod Menu**

## Existing Save Files
>[!WARNING]
It is strongly advised against to load up any continue save or chapter checkpoint when first installing the Mod menu or when switching between Mods. These overwrite any Mods and usually instantly break the mod tools. If you need to load a save, only load those that start a chapter from the beginning.

## Mod Menu

### Controls
- After you are ingame, you can open my mod menu at any time by using the R3 button (controller) or F12 (PC)
- This menu can be operated with a controller (d-pad) or with the movement keys on PC (arrow buttons). Confirmation is with X (controller) or Enter (PC). NOTE: If you find that the down arrow on PC acts as a confirm button too, change the "move down" alternative key binding in the game's PC options to some button you never use freeing the down arrow, but keeping the S key in primary or whatever you use there
- To navigate back one layer if you are multiple menu layers in, you can use Circle (pad) or the Escape key (PC). Using R3/F12 at any point will fully close the menu again
<a name="controls-page-menu"></a>
- If you happen to be in a long list menu, you can cycle pages of items using L1/R1 (pad) or F1/F2 (PC)
<a name="controls-slider-menu"></a>
- Pages where you can adjust a number value, d-pad up/down (pad) or W/S (PC) will adjust the value up/down. This button can be held and will eventually speed up the increase/decrease. On PC you can also use the mousewheel. Additionally a multiplicator for faster adjustments can be set with d-pad right/left (pad) or A/D (PC)
<a name="controls-free-type-menu"></a>
- There are also some pages that expect an arbitrary name or number input. This works by typing it in via the keyboard. Enter to confirm and backspace to delete one character
<a name="controls-alt-confirm"></a>
- NOTE: Select (pad) and left mouse click (PC) also work as a confirmation key alongside X/Enter on my menus. When you pause the game using the menu, the game turns off the X/Enter button, in this case you absolutely need the Select/left mouse click button to keep operating the menu and also unpause the game again

### Menu Item Explanation:

#### **Characters**
Allows to manipulate Characters and Objects in the chapter.
Visible Only will show both Characters and Objects in a single list, as long as they are currently *completely* in your camera view.
The character/object list can stretch across multiple pages. See [Controls](#controls-page-menu) section to find out how to switch pages. The active player character for this chapter is quickly available under the special name: "0GMCurrentPlayer"
 - Show/Hide: Show/Hides the character/area
 <a name="characters-set-catalog"></a>
 - Set Catalog: Change the character model in real time by typing in its ID. This is a free typing menu. See [Controls](#controls-free-type-menu) section for operation notice. A list of available catalog IDs is available under: [Catalog List](Resources/CatalogList.json)
 - Enable Cloth Physics/Disable Cloth Physics: Disable Havoc cloth physics on this character. This makes the character leave its hair and clothing behind
 - Teleport To: Warp the player to this character's position
  <a name="characters-apply-composite"></a>
 - Apply Composite: Apply a character composite (a blend between two or more character meshes) to the currently selected character. These are undone when you switch between chapters. Composites are available on request. If you don't have any this option will be missing
 - Unregister (dangerous): Completely remove the character/area from the scene. Can often crash when used with characters (preferably use "Hide" instead whenever possible)

# **Detroit Ingame Mod Menu**

## Installation

Installation is fairly simple. Just drop **both** the BigFiles and Mods folder as they are into your Detroit game directory. And that's already it!

Obviously there is quite a bit to the tools and a few "good-to-knows", so there is a comprehensive Readme available, see: [2. Readme Mod Menu.md](2.%20Readme%20Mod%20Menu.md)

Please read through the documentation carefully and then you can learn the rest by doing it, which usually works out fine. If you encounter any issues, please first check if the Readme answers it. If it doesn't, you can always ask me on Discord of course :)

## The AddOn System
Included with this package is the AddOn system, a convenient new way to manage, share and organize Detroit Mods without affecting the main game files at all. To understand this system, check out [AddOn Overview.md](AddOn%20Overview.md).

# **Detroit AddOn Mod System**

## Installation

Installation is fairly simple. Just drop **both** the BigFiles and Mods folder as they are into your Detroit game directory. And that's already it!


## The AddOn System
Included with this package is the AddOn system, a convenient new way to manage, share and organize Detroit Mods without affecting the main game files at all. To understand this system, check out [AddOn Overview.md](AddOn%20Overview.md).
